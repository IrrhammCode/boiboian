# Boi-Boian — complete digital rules

Traditional neighbourhood variants differ; **this file wins**. Feel numbers: `play-feel.md`. Art: `style-lock.md`.

## Fantasy
Street athletes on a neo-street dusk court. Knock a ceramic tile pyramid with a ball, rebuild it under tag-fire (pass, don't run with the ball), shout **Boi**. Rules from traditional Boi-boian — playable by anyone, not a kids-only toy.

## Teams
- **Teal (Rebuild)** / **Mango (Tag)** — duty swaps each round; knocker rebuilds (traditional).
- **5v5**. Player controls 1 kid; swap among living teammates.
- Match: first to **2 Boi**. Jam: 1P vs AI.

## Field
- Court **16×16 m**. Pyramid centre. Throw line **5.0 m** (−Z). Rebuild zone **r 1.8 m**.

## Equipment
- Ball Ø **0.18 m**. Pyramid **12** shards / 4 courses.

## Phases
**A Line-up** → countdown → **B Knock** (≤3 throws; pity scatter after 3 misses) → duty flip → **C Live** → **D Resolve**.

### Knock
Throw from behind line. Collapse → Phase C. Knock team becomes rebuild; waiters become tag.

### Live — Tag side
- Cannot run while holding ball (root / ≤0.4 m/s).
- Pass to relocate. Hold max **1.8 s** then forced drop.
- Tag throw charge 0.15–0.7 s; body hit ~0.28 m = out.
- Max **2** camp rebuild zone.
- Loose ball pickup 0.35 m.

### Live — Rebuild side
- Pick one shard; max **2** carriers; run allowed while carrying.
- Place in zone on valid ghost slot; **0.35 s** channel; cancel if tagged.
- Courses: base free first; upper needs support below.
- **Boi:** full pyramid + call (button or auto 0.5 s in zone).

### Resolve
- Boi → rebuild +1. Wipe (all rebuilders out) → tag +1.
- Timer 100 s: if ≥8 shards placed → rebuild wins round; else tag.

## Forbidden
Full-speed run with ball · auto-magnet place · always-hit lock-on · mid-round respawn · glyphs on meshes.
