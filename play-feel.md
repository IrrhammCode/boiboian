# Boi-Boian — play feel

Goal: **40% playability** — phone-first, 60–90 s rounds, skill ceiling.

## Skill loop
1. Aim knock (ribbon + charge)
2. Readable scatter (~1.2 m)
3. Hot potato — no run with ball
4. Rebuild under fire (0.35 s place channel)
5. Tag out
6. Boi package

## Controls
Desktop: WASD, mouse aim, LMB charge throw, RMB pass, E pick/place, Tab swap, Space Boi.  
Mobile: stick + Throw / Pass / Swap / Action.  
Gamepad: L-stick move, R-stick aim, RT throw, X pass, A action, Y swap.

## Juice
Knock: hit-stop + cam punch + shatter. Pass: trail + chain pip. Tag: directional shake + 80ms stop. Near-miss whoosh. Boi: 0.55s freeze + flash + shout.
